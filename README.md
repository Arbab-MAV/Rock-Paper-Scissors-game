🎮 Rock Paper Scissors Game  
A simple Rock Paper Scissors game built with HTML, CSS, and JavaScript.  
This project is designed as a beginner-friendly practice to understand DOM manipulation, event handling, and basic game logic.  

---

📌 Features  
- User vs Computer gameplay.  
- Randomized computer choices for fair play.  
- Real-time score tracking (User and Computer).  
- Dynamic messages showing game results (Win, Lose, Draw).  
- Clean and responsive UI design.  

---

🛠️ Technologies Used  
- **HTML5** – structure of the game.  
- **CSS3** – styling and layout.  
- **JavaScript (ES6)** – game logic and interactivity.  

---

🚀 How to Run  
1. Clone or download this repository.  
2. Open the `index.html` file in your browser.  
3. Click **Rock**, **Paper**, or **Scissors** to start playing against the computer!
